Who this is for

For small teams running on Microsoft 365 whose requests cross shared mailboxes, SharePoint folders and spreadsheets. This is custom integration planning around licensed Microsoft services, not a claim that a Copilot subscription does everything automatically.

Problems worth solving

Requests arrive without a clear owner

An attachment in a shared mailbox can sit between sales and operations because nobody knows which team owns the next step. We can classify an authorized request, suggest its owner and prepare a task with a link back to the source.

More access is not always better access

A workflow that only needs one document library should not casually read the whole tenant. We map selected content, user permissions and the human decision point before choosing delegated or application access.

What a custom workflow could look like

  1. A permitted mailbox or selected folder provides an intake item through an approved Graph connection.
  2. The workflow checks identifiers, file types and existing task references to avoid processing the same request twice.
  3. AI summarizes approved content and prepares an internal task or draft response with source links and uncertainty notes.
  4. A person checks the draft before external sending, sharing changes or accounting posting. Sensitive requests route to the designated reviewer.
  5. The system records the outcome and reports expired consent, throttling or unavailable files for follow-up.

Illustrative design only—not a client story, measured result or demonstration of a live integration.

Access and plan limitations

Microsoft Graph access follows the services your users are licensed for, the permissions granted and tenant policy. Most standard APIs are included within license and usage limits; metered APIs may add Azure charges. Delegated permissions are preferred where sufficient; application permissions require admin consent and can be broad, so scope restrictions need explicit design. Microsoft 365 or Copilot branding does not grant automatic API access to every feature. Shared mailboxes, SharePoint restrictions and tenant consent policies must be tested.

Questions before you start

Do I need Microsoft 365 Copilot?

Not necessarily for a custom Graph-based workflow. Copilot features and licenses are separate; we confirm whether your use case needs them rather than assuming they are included.

Can it read every employee’s inbox?

Not by default. We define the minimum mailboxes and permissions required. Broad application access is not a shortcut and must be explicitly approved and restricted.

Will it send replies without me?

This proposed workflow prepares drafts for review. It does not grant new sending or sharing permissions; a person approves the outward action.

Can we include invoices?

Yes as a possible scoped intake workflow, not a tested capability claim. Your bookkeeper reviews accounting entries before posting and a CPA reviews tax items. No payments or filing are automated.
